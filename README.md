# 合并文明 · 可玩原型

TypeScript + Vite 网页原型，对应设计文档的 MVP 范围：3 合 1、建筑占地随等级增长（1×1 → 1×2 → 2×2 → … → 5×5）、单块地 8×8（整局固定），买相邻地块拼接扩张，建筑可跨地块、前 3 个时代、6 条建筑链、4 种资源 + 人口。

## 运行

```bash
npm install
npm run dev     # 本地开发，浏览器打开提示的地址
npm run build   # 打包到 dist/，可以直接放到任何静态网页空间
npm run sim     # A/B 两种机器人同种子各跑 30 局
npm run sim -- A 3   # 策略 A、种子 3，打印过程
```

## 文件

- `src/data.ts`：所有建筑、资源、时代、奇迹的数值。调平衡只改这里。
- `src/game.ts`：纯游戏逻辑（召唤、合并、回合结算、奇迹），不依赖界面，方便以后移植或写测试。
- `src/main.ts`、`src/style.css`：界面和拖拽交互。
- `scripts/sim.ts`：平衡模拟器。

## v10 规则与地图模拟器（2026-11-27）

## 当前规则（v9）

- 数据基准：《建筑定义.xlsx》的原始 → 青铜 → 铁器三个时代（幸福度、陶器、砖块链暂未接入）。
- 城市核心：唯一，原地花资源升级（没空地时自动挪开挡路建筑，挪不下才拒绝），等级 = 可拥有地块数，并决定时代和建筑最高等级（原始 3 / 青铜 4 / 铁器 5）。升到卫城即通关。
- 合并：同种建筑边相邻连成一组（一条线、直角、T 形、十字都算），满 3 个自动合并，一次最多 9 个；合 9 个直接升 2 级（有 2 级可升时）。拖动时高亮会参与合并的建筑并预览结果和返还。
- 新建筑位置：尽量覆盖最后放下的那座建筑的位置，优先和同种建筑并排（可旋转）；放不下就从那里顺时针一圈一圈找空位，同样优先并排。合出的新建筑若又凑够 3 个会连锁合并（combo）。
- 合并规则：合成只增产、不加新原料（产出 = 3 座之和 ×`MERGE_GAIN` 1.2，工人 ×`MERGE_WORKERS` 0.8，投入 = 3 座之和）；合并不换资源（采石场 → 切石场 → 石料作坊…）。青铜、铁器维护费只在住房和核心上。表里每条链只保留入门建筑数值，更高级由规则推出。
- 核心升级送下一阶段入门建筑：氏族长屋送 2 座青铜矿场 + 1 座炼制工坊，城邦议事厅送铁矿坑 + 铁匠铺。
- 重摇：每回合免费重摇卡 1 次，之后每次 2 行动力。补缺口卡优先给“差 1 个就能凑满 3 个”的对口建筑。
- 地图统一为平地，没有地形加成；原料类建筑（粮、木、石、矿）产出在表格数值上 ×1.4（`RAW_OUTPUT`）。驿站光环 2 格内 +5%/+10%，不叠加。
- 供应链：青铜矿场吃木和石，青铜作坊吃铜、木、石，铁器同理。
- 选卡：每回合 1 次 3 选 1 + 随机分配，卡面显示“能放下 x/y 座”。
- 行动力：每回合 5 点（每个时代 +1）。移动/旋转花费 = 建筑格数；合并返还一次移动（被合建筑的格数），每多合 1 个再返还一次；连锁合并返还翻倍（`RULES.comboMode`：none / double / ramp）。
- 买地：除资源外还要花行动力，第 2 块 5 点，之后每块 +2（`RULES.apPlotBase`/`apPlotStep`，-1 = 花掉一整回合行动力）。核心升级费用倍数 `RULES.coreCostMult`。
- 卖出：拖到垃圾桶卖出，返还 格数 ÷ 4（向下取整，不足 4 格返还 0）。
- 结算：原料先吃库存，不够就停工但不扣心；只有断粮扣心。失败下回合多 1–2 次选卡，3 次失败游戏结束。工人先派粮食，再派最缺的资源；空房不吃维护费。
- 调参：`GAIN=1.3 WORKERS=0.8 CV=0,2,3,5,10,24 npx tsx scripts/tune.ts A`；模拟器会把缺口分成基础（粮木石）和进阶（铜青铜铁）两类，统计每类缺口是靠合并、选卡还是重摇改善的，并按“缺口事件”（从出现到消失）统计解决方式和用时。
- `npm run sim` 用同一组种子对比 A“紧凑、见合就合”、B“早扩地、先看原料再合”、C“主动找连锁合并”三种机器人，统计跳过的合并、非补缺口选卡、失败前是否有预警，以及行动力花在移动、合并返还、卖出返还和回合末浪费各多少、连锁次数、卖出数。环境变量 `AP`、`APE`、`CM`（连锁奖励 none/double/ramp）、`APP=5,2`（买地行动力）、`CORE=1.3`（核心费用倍数）、`PICKS=1`（每回合选卡次数）可改这些规则。

## v10 可操作测试版

- 本地跑：`npm install` 后 `npm run dev`，打开终端里显示的地址（首页就是 v10；旧的 v9 在 `/v9.html`）。
- 免安装：直接用浏览器打开 `play/v10.html`（单文件，已打包）。重新打包：`npm run build` 后把 `dist/assets/index-*.js/css` 内联进去。
- 玩法：每个大回合可领 3 批建筑；拖动建筑移动（花行动力，按占地格数）；3 座同种同级连在一起自动合并；选中后按 R 或点“旋转”；点虚线框买地；仓库里的建筑点一下卖出。顶部色块是各资源的供给 ÷ 需求（绿 ≥1.25，黄 ≥1，红 <1）。
